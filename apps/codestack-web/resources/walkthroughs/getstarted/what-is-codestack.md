# What is CodeStack?

With CodeStack, you spin up fresh, automated dev environments for each task, in the cloud, in seconds.

- Develop a new feature? Start a new workspace.
- Review a pull request? Start a new workspace.
- Fix a bug in production? Start a new workspace.

You can even run multiple workspaces in parallel and they are 100% isolated from each other.

## User interface

As you notice, CodeStack looks & feels like VS Code - except it runs in a browser. On CodeStack, you can install extensions, apply themes and use a terminal just as you're used to from your local computer.

## Browser extension

To be most productive with CodeStack, it is best if you [install the browser extension](https://www.codestack.io/docs/configure/user-settings/browser-extension). It will add a convenient "CodeStack" button when you look at your repo, an issue or a pull request.
