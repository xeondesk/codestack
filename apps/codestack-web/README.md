# CodeStack Web integration

**Notice:** This extension is bundled with CodeStack Code. It can be disabled but not uninstalled.

## Features

This extension enables [CodeStack's VS Code Browser integration](https://www.codestack.io/docs/references/ides-and-editors/vscode-browser).

## Source code and bug tracking

The source code can be found in the [extension's respective folder in khulnasoft-bot/codestack-code](https://github.com/khulnasoft-bot/codestack-code/tree/master/codestack-web).

Bug reports should be filed at [khulnasoft-bot/codestack](https://github.com/khulnasoft-bot/codestack).
