# CodeStack Classic Remote

> **Note**: If you’re looking for the [CodeStack](https://app.codestack.io) experience, please install the [CodeStack extension](https://marketplace.visualstudio.com/items?itemName=codestack.codestack-flex).

This extension is automatically installed by [CodeStack Classic extension](https://marketplace.visualstudio.com/items?itemName=codestack.codestack-desktop) inside workspaces to provision extensions, task terminals, etc. You should not install this extension manually.
